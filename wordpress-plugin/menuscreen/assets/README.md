# Icon assets

- **icon-menu.svg** — the small, single-color icon used live in the
  WordPress admin sidebar menu (loaded and base64-encoded by
  `MenuScreen_Admin::register_menu()`). WordPress recolors it
  automatically to match the current admin color scheme, which is why
  it's plain black rather than the brand color.
- **icon.svg** — the full-color square icon (brand orange background,
  white screen/menu-lines mark). Not used anywhere in the running
  plugin yet — it's here for future use as a WordPress.org plugin
  directory listing icon, a favicon, or general branding.
